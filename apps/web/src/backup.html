Unencrypted bearer credential

Anyone obtaining a usable copy may later exercise that ticket's eligible claim/refund authority. Importing another copy does not revoke previously copied files. The application cannot revoke stolen copies.

Keep the file private. Downloads, OneDrive, device backups, messaging apps and screenshots may expose copies. This application does not encrypt the file or put it in cloud storage.

Drafts and pending issuance attempts cannot be exported. If server issuance succeeded but the reply or local finalization failed, keep this browser data and retry the same attempt before exporting. Losing storage in that gap has no portable recovery here.

Older finalized credentials require one successful same-attempt issuance retry to enable export. A backup restores the claim credential, not the issuance token or payment screen.
